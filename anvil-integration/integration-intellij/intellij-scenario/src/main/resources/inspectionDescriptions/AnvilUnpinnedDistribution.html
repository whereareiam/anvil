Reports Distribution.remote(version, "latest") in a scenario that is not manual.

Automated runs refuse the latest build, because the same test would download a different server over time. Pin a build number, use Distribution.pinned(version, sha256), or mark the scenario with manual(true) in the same method.

Example:

.distribution(Distribution.remote("1.21.11", "latest")) // reported
.distribution(Distribution.remote("1.21.11", "132"))    // pinned
