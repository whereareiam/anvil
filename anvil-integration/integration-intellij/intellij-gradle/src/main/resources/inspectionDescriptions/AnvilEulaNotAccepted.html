Reports a Gradle build script that applies the me.whereareiam.anvil or me.whereareiam.anvil.junit plugin without accepting the Minecraft EULA.

Anvil refuses to start servers until the build accepts the EULA, in Gradle tasks and in the IDE alike. The quick fix adds acceptEula() to the script's anvil block, or adds the block. 

anvil {
    acceptEula()
}
