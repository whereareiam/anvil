# Anvil branding assets

These three SVGs are the canonical Anvil logo assets:

- `anvil-light.svg` is the light-theme plugin logo.
- `anvil-dark.svg` is the dark-theme plugin logo.
- `anvil-transparent.svg` is the backgroundless toolbar mark.

Product resources keep their required names and packaging locations. They should be regenerated
from these files when their dimensions or surrounding product treatment need to change.
